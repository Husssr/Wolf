# ค่ำคืนหมาป่า (Werewolf Night)

เกมมนุษย์หมาป่าแบบเล่นต่อหน้า ใช้ **ไอแพดกลาง 1 เครื่องเป็นผู้คุมเกม** (พูดบรรยายภาษาไทย จับเวลา) และ **โทรศัพท์ของทุกคนเป็นบัตรบทบาทลับ**
ไม่ต้องติดตั้งแพ็กเกจเพิ่ม ใช้ Node.js 18 ขึ้นไปอย่างเดียว

## เล่นบนเครื่องตัวเอง (ทดลอง)
```
node server.js
```
เปิด http://localhost:3000 บนไอแพด กด "สร้างห้องใหม่" แล้วให้เพื่อนที่อยู่ใน Wi-Fi เดียวกันเปิด `http://<ไอพีเครื่องคุณ>:3000`

## ขึ้นออนไลน์ฟรีด้วย Render (ได้ลิงก์ถาวร)
1. สร้างที่เก็บโค้ดบน GitHub (github.com → New repository) แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (`server.js`, `package.json`, `render.yaml`, โฟลเดอร์ `public`)
2. เข้า https://render.com สมัครด้วยบัญชี GitHub
3. กด **New → Web Service** เลือกที่เก็บโค้ดที่เพิ่งสร้าง
4. ตั้งค่า Runtime = **Node**, Build Command ปล่อยว่างหรือใส่ `echo ok`, Start Command = `node server.js`, Instance Type = **Free**
5. กด Deploy รอประมาณ 2–3 นาที จะได้ลิงก์ เช่น `https://werewolf-night.onrender.com`

หมายเหตุแพ็กเกจฟรีของ Render: เซิร์ฟเวอร์จะหลับถ้าไม่มีคนใช้ 15 นาที เปิดลิงก์ครั้งแรกอาจรอ 30–60 วินาที ให้เปิดหน้าเว็บไว้ก่อนเริ่มเกมสัก 1 นาที
ห้องเกมเก็บในหน่วยความจำ ถ้าเซิร์ฟเวอร์รีสตาร์ท ห้องจะหายและต้องสร้างใหม่

## วิธีเล่น
1. ไอแพด: เปิดลิงก์ → **สร้างห้องใหม่** ตั้งค่าบทบาท/กติกา แล้ววางไอแพดกลางวง
2. เพื่อนๆ: เปิดลิงก์ในโทรศัพท์ ใส่รหัสห้อง 4 หลักกับชื่อ (หรือสแกน QR บนไอแพด)
3. ผู้คุมกด **เริ่มเกม** ทุกคนกดค้างเพื่อดูบทบาทบนโทรศัพท์ แล้วกดรับทราบ
4. ไอแพดพูดนำทั้งเกม ("ทุกคนหลับตา หมาป่าลืมตา ...") ใครที่ถึงตาจะมีเมนูเลือกบนโทรศัพท์ และโทรศัพท์สั่น (Android)
5. ตอนกลางวันมีนับเวลาอภิปราย แล้วโหวตลับบนโทรศัพท์หรือนับสามแล้วชี้ (ตามที่ตั้งไว้)

เสียงพูดใช้เสียงภาษาไทยของเครื่องไอแพด/เบราว์เซอร์ (iPad มีเสียง Kanya ในตัว ถ้าไม่มี จะแสดงข้อความขนาดใหญ่แทน)

## กติกาที่ใช้
- ลำดับกลางคืน: คิวปิด (คืนแรก) → คู่รัก → บอดี้การ์ด → หมอ → หมอดู → หมาป่า → แม่มด
- หมอ/บอดี้การ์ดป้องกันคนเดิมติดกันสองคืนไม่ได้ หมอป้องกันตัวเองได้
- ยาพิษของแม่มดและการยิงของนักล่าทะลุการป้องกัน บอดี้การ์ดตายแทนเมื่อคนที่ปกป้องถูกหมาป่าโจมตี (ถ้าหมอช่วยไว้แล้ว บอดี้การ์ดไม่ตาย)
- คะแนนโหวตเสมอกัน ไม่มีใครออก
- ชนะ: ชาวบ้านเมื่อหมาป่าหมด / หมาป่าเมื่อจำนวนไม่น้อยกว่าที่เหลือ / คู่รักต่างฝ่ายเหลือกันสองคน / คนบ้าถ้าถูกโหวตออก
